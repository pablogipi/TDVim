Intro                                  *tdvim-intro*

Install:
Run this command from your HOME folder:
    UNIX:
        git clone -b vim-packages https://github.com/pablogipi/TDVim.git .vim
    Windows:
        git clone -b vim-packages https://github.com/pablogipi/TDVim.git vimfiles

Update:
From vim run this command:
    :TDVimUpdate

Development                     *tdvim-development*

- Moving Around:
    - Grep current word:                        <F4>
    - Grep in project:                          <Shift-F4>
    - Go to previous change position:           [d
    - Go to next change position:               ]d
    - Search Changes:                           <F11>
    - Go to previous jump position:             [j
    - Go to next jump position:                 ]j
    - Search Jumps:                             <Shift-F11>
    - Go to start of next function:             ]]
    - Go to next end of function:               ][
    - Go to previous start of function:         []
    - Go to previous end of function:           [[
    - Jump to prev block of same indent:        [=
    - Jump to next block of same indent:        ]=
    - Jump to prev line with more indent:       [+
    - Jump to next line with more indent:       ]+
    - Jump to prev line with less indent:       [-
    - Jump to next line with less indent:       ]-
    - Jump to prev line with different indent:  [;
    - Jump to next line with different indent:  ];
    - Jump to start of the current block scope: [p
    - Jump to end of the current block scope:   ]p
    - Select current block:                     ii
    - Select current block + one extra line  at beginning: ai
    - Select current block + two extra lines at beginning and end: aI
    - Python:
      - Class text object:                      c
        - Function text object:                 f
        - Doc String                            d
        - These motion are valid:               ic, af, dif, etc ...
      - Extended Match Pairs (matchpairs):      %
        - Match loop oppsite:                   g%
        - Prev and Next Matched                 [%, ]%

      - Black formatter                         :Black

Unimpaired                         *tdvim-unimpaired*

*[b*     |:  bprevious|. Previous Buffer
*]b*     |:  bnext|. Next Buffer
*[B*     |:  bfirst|. First Buffer
*]B*     |:  blast|. Last Buffer
*[q*     |:  cprevious|. Previous Error
*]q*     |:  cnext|. Next Error
*[Q*     |:  cfirst|. First Error
*]Q*     |:  clast|. Last Error
*[f* :        File preceding current one
*]f* :        File succeeding current one
*[<Space>* :  Add [count] blank lines above the cursor.
*]<Space>* :  Add [count] blank lines below the cursor.
*[e* : Exchange the current line with [count] lines above it.
*]e* : Exchange the current line with [count] lines below it.
*[c* :        Previous Change
*]c* :        Next Change
*[j* :        Previous Jump
*]j* :        Next Jump
*[h* :        Previous Hunk
*]h* :        Next Hunk
*]t* :        Jump to tag
*[t* :        Go back from tag stack
*]T* :        Search tag in Gtags
*[T* :        Show back references in Gtags
*]s* :        Jump to next search in location window
*[s* :        Jump to previous search in location window
*]S* :        Jump to last search in location window
*[S* :        Jump to first search in location window
*]l* :        Jump to next line with same indentation
*[l* :        Jump to previous line with same indentation
*]L* :        Jump to next line with less indentation
*[L* :        Jump to previous line with less indentation
*[`* :        Jump to previous local mark 
*]`* :        Jump to next local mark 

OPTION TOGGLING                                 *unimpaired-toggling*

On	Off	Toggle	Option
*[ob*	*]ob*	*yob*	'background' (dark is off, light is on)
*[oc*	*]oc*	*yoc*	'cursorline'
*[od*	*]od*	*yod*	'diff' (actually |:diffthis| / |:diffoff|)
*[oh*	*]oh*	*yoh*	'hlsearch'
*[oi*	*]oi*	*yoi*	'ignorecase'
*[ol*	*]ol*	*yol*	'list'
*[on*	*]on*	*yon*	'number'
*[or*	*]or*	*yor*	'relativenumber'
*[os*	*]os*	*yos*	'spell'
*[ou*	*]ou*	*you*	'cursorcolumn'
*[ov*	*]ov*	*yov*	'virtualedit'
*[ow*	*]ow*	*yow*	'wrap'
*[ox*	*]ox*	*yox*	'cursorline' 'cursorcolumn' (x as in crosshairs)
