# TDVim

Vim distribution for TDs

## Install:
    git clone -b vim-packages https://github.com/pablogipi/TDVim.git  [.vim|vimfiles]

On Linux/Unix you can clone onto your .vim folder, on Windows clone onto
the vimfiles folder in yout home directory.

Once the repository is cloned just run :TDVimUpdate to finish installation.
This will install all plugins as vim packages using git submodules.

## Update:
From vim run this command:
    :TDVimUpdate

# Modes
TDVim can work in normal mode, this is a lite version wher many features for
development are not installed and we have  a simpler editor for quick edits

If vim (or gvim) is opened witrh  a folder as argument, like `gvim .`.
Thje we will open in __Dev Mode__

## Dev Mode
This is where TDVim really shines opening a full fledge development environment
built around Vim.
